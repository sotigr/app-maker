# Architecture notes

Module: `organon`. Layout follows spec §15.1. Layer rules: §15.2 + ADR 0004 (enforced by depguard,
`.golangci.yml` generated by `scripts/gen-depguard.sh`; tests excluded).

| Layer | May import |
|---|---|
| `api` | std, `kernel`, other contexts' `api` (acyclic) |
| `domain` | std, `kernel`, own `domain`, any `api`, pure libs (expr, jsonschema/v6, apd/v3, uuid) |
| `application` | std, `kernel`, own `domain`, any `api` |
| `infrastructure` | own domain+application, kernel, platform, any `api`, drivers |
| `interfaces` | own application, kernel, platform, any `api` |
| `platform` | std, third-party, `kernel` only |
| `internal/app` | composition root shared by cmd/organond and cmd/organon (unrestricted) |

## Request flow (write)
HTTP handler → `Service.Execute` → resolve (types, `$` refs) → loadAll (GetMany) → per op:
authorize (Authorizer.Check; 404 if target unreadable) → audience → checkWritable → validateView
(merges coercion errors) → transitions/guards → apply/computed/timestamps → validateStorage
(invalid_state for hidden fields) → beforeWrite hook → commit (mutations, events→publish_events,
CommitHooks jobs) → project through audience.
